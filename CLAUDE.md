# Ведомственная карта ФГИС УПЧ

Интерактивный прототип аналитической панели для министерств, ведомств, прокуратуры и губернаторов (хакатон по кейсу ФГИС УПЧ, защита 23.10.2026). Все данные, кроме годовых объемов по ведомствам из доклада Уполномоченного за 2025 год, демонстрационные.

## Команды

- `npm install`, `npm run dev`: локальный запуск (http://localhost:5173/fgis-upch-map/).
- `npm run build`: проверка типов и сборка в `dist/`.
- `npm run data`: перегенерировать демонстрационные данные (детерминированно, seed в `scripts/generate-data.ts`).
- `npm run topo`: пересобрать `public/data/regions.topo.json` из `regions.geojson`.
- Публикация: push в `main` запускает `.github/workflows/deploy.yml` (GitHub Pages).

## Структура

- `src/config/reference.ts`: единый справочник 89 регионов (код субъекта для адресов, код GeoJSON, ФО, население), ведомства и темы, категории прав 01-07 из документа команды «Классификация», список подключенных регионов.
- `src/config/thresholds.ts`: фиксированные пороги пяти классов карты.
- `src/config/priority.ts`: формула приоритета обращения из документа «Ранжирование».
- `src/logic/recommendations.ts`: правила рекомендаций R1-R8 (описаны в шапке файла и в README).
- `src/data/aggregate.ts`: все расчеты показателей; проценты только из абсолютных значений.
- `src/state/filters.ts`: фильтры в адресе страницы (ved, topic, metric, cat, p, status, inst, mode).
- `src/components/RussiaMap.tsx`: карта (d3-geo, коническая равновеликая проекция, центральный меридиан 100° в.д., d3-zoom, выноски для Москвы, Санкт-Петербурга, Севастополя).
- `src/pages/*`: Обзор, Карта, Ведомства, Регион, Типовые обращения, Обращения, Карточка, Отчетность.
- `scripts/generate-data.ts`: генератор `public/data/demo-data.json`, `institutions.json`, `cases.json`.

## Правила текста интерфейса

Русский язык, без буквы «ё», без длинных тире, числа с пробелом между разрядами, проценты с запятой. Фраза «Данные могут быть неточными» в подвале каждой страницы и в справках.
