# Ведомственная карта ФГИС УПЧ

Интерактивный прототип аналитической панели ФГИС УПЧ для министерств, ведомств, органов прокуратуры и губернаторов. Панель смотрит на обращения граждан глазами адресата: главный фильтр «Ведомство». Министерство видит свою сферу по всей России, губернатор видит свой регион в разрезе всех ведомств.

**Опубликованный сайт:** https://daria71321-netizen.github.io/fgis-upch-map/

> Демонстрационный режим. Реальны только годовые объемы обращений, направленных Уполномоченным в ведомства (Доклад Уполномоченного по правам человека в РФ за 2025 год, с. 558-559). Распределение по регионам, темам и месяцам, сроки, доли и карточки обращений сгенерированы для демонстрации и не являются официальной статистикой.
>
> Карта для помощи, а не для наказания: показатели являются основанием для дополнительной проверки и анализа, а не для санкций.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/fgis-upch-map/. Сборка: `npm run build`. Каждый push в `main` пересобирает сайт через GitHub Actions.

## Ссылки на экраны

Адреса работают как постоянные ссылки: `#/region/38?ved=mo` открывает Иркутскую область в слое Минобороны. Параметры: `ved` (mo, prok, mvd, fsin, trud), `topic`, `metric` (rate, dyn, days, restored, repeat), `cat` (01-07), `p` (2026, 12m, 2026q3, 2026-09, 2025, 2024), `mode=gov`, `inst=1`.

## Данные

- Обновить демонстрационные данные: `npm run data` (скрипт `scripts/generate-data.ts`, фиксированный seed, у всех одинаковые цифры). Результат: `public/data/demo-data.json` (ряды регион × ведомство × тема × месяц: жалобы, ответы, сумма дней ответа, просрочки, завершенные, с установленным нарушением, восстановленные, повторные), `institutions.json` (учреждения МВД и ФСИН с координатами), `cases.json` (карточки обращений).
- Годовые суммы по ведомствам совпадают с докладом: Минобороны 20 283 (2025) и 14 432 (2023), прокуратура 8 347, МВД 1 283, ФСИН 889 (2025) и 1 441 (2023), Минтруд 140 (плюс демонстрационные обращения в отделения СФР). Остальные годы демонстрационные.
- 26 регионов подключены к ФГИС УПЧ, 59 в режиме «Оценка», 4 без данных. Справочник регионов один: `src/config/reference.ts`.
- Категории прав и подкатегории взяты из документа команды «Классификация», формула приоритета из документа «Ранжирование» (`src/config/priority.ts`).

## Границы регионов

`public/data/regions.geojson`: 89 субъектов РФ. Источник: click_that_hood (на основе OpenStreetMap, лицензия ODbL) для 83 субъектов и Natural Earth (общественное достояние) для Республики Крым, Севастополя, ДНР, ЛНР, Запорожской и Херсонской областей. Файл собран в прошлом прототипе команды. Для карты используется `regions.topo.json` (`npm run topo`). Проекция коническая равновеликая Альберса, центральный меридиан 100° в.д., поэтому Чукотка не разрывается.

## Пороги классов карты

Пороги фиксированные, одинаковые для всех ведомств (`src/config/thresholds.ts`).

| Показатель | Класс 1 | Класс 2 | Класс 3 | Класс 4 | Класс 5 |
|---|---|---|---|---|---|
| Жалоб на 10 тыс. жителей, к среднему по России | меньше 0,7× | 0,7-1× | 1-1,3× | 1,3-2× | 2× и больше |
| Динамика к прошлому году | меньше -10% | от -10 до 0% | от 0 до +15% | от +15 до +40% | +40% и больше |
| Срок ответа ведомства | до 15 дней | 16-25 дней | 26-35 дней | 36-45 дней | больше 45 дней |
| Доля восстановленных прав (обратная) | 60% и больше | 45-60% | 30-45% | 20-30% | меньше 20% |
| Повторные обращения | меньше 5% | 5-10% | 10-15% | 15-25% | 25% и больше |

Регион не подключен к ФГИС УПЧ: светло-серая штриховка, срок ответа и доля восстановленных прав не считаются, число жалоб показывается как оценка. Нет данных: темно-серый.

## Правила рекомендаций

`src/logic/recommendations.ts`:

1. **Рост по теме:** динамика темы к прошлому году +40% и больше (класс 5) при 10+ жалобах: высокий уровень; от +15 до +40% при 15+ жалобах: средний.
2. **Срок ответа:** класс 4 (36-45 дней): средний, класс 5: высокий. Для Минтруда и СФР адресат губернатор.
3. **Восстановленные права:** меньше 30% при 10+ завершенных случаях с нарушением: средний.
4. **Повторные обращения:** 15% и больше при 20+ жалобах: средний (признак формальных ответов).
5. **Прокуратура:** один тип жалоб на один орган 5 и более раз за квартал: высокий, «включить орган в план проверок».
6. **МВД и ФСИН:** учреждение с 10+ жалобами за последние 6 месяцев: средний, «проверка совместно с ОНК».
7. **Высокая обращаемость:** вдвое выше среднего по России: информационный, «проанализировать причины».
8. **Регион не подключен или нет данных:** информационный, «подключение к ФГИС УПЧ».

Рекомендации формулируются как основание для дополнительной проверки; вывод о нарушении прав только по количеству обращений не делается.

## Технологии

React 18, TypeScript, Tailwind CSS, Vite, d3-geo и d3-zoom (SVG), Recharts, HashRouter. Серверной части нет, все данные в статических JSON. Дизайн-система: `DESIGN.md`.
